## 🎯 Loyiha Haqida

**FoodMaster** — bu zamonaviy va interaktiv onlayn taomlar sayti bo'lib, foydalanuvchilarga:

- 🍽️ **Menyu bilan tanishish**
- 🛒 **Taomlarni savatchaga qo'shish**
- 📞 **Buyurtma berish**
- ⭐ **Mashhur taomlarni ko'rish**

imkoniyatlarini taqdim etadi.

### Asosiy Maqsadlar:
- 🍔 Restoran yoki oshxona uchun onlayn menyu
- 🛍️ Oddiy va qulay buyurtma berish tizimi
- 📱 Barcha qurilmalarda mukammal ko'rinish
- 💰 Real vaqtda savatcha hisobi

## Yangi Taom Qo'shish
script.js dagi menuItems massiviga qo'shing:
```bash
{
    id: 31,
    name: "Taom nomi",
    category: "lunch",  // breakfast, lunch, dinner, drinks, desserts
    price: 35000,
    desc: "Taom haqida qisqacha",
    image: "rasm_url",
    rating: 4.5
}
```
## Yangi Kategoriya Qo'shish
index.html dagi .menu-filters ga qo'shing:

```bash
<button class="filter-btn" data-category="newcategory">Yangi kategoriya</button>
```
